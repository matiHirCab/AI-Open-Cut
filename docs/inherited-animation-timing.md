# Inherited animation and timing

Issue #42 adds schema-26 timing fields to visual controllers. Group and component-instance items accept optional `staggerMs` from 0 through 60000. A repeater descriptor accepts optional signed `timeOffsetMs` from -60000 through 60000. Missing fields mean zero and preserve older project output.

Direct visual children of a group or a component definition are ranked from zero in canonical track, z-index, stack-order and ID order. Hidden and clipped visual children keep their ranks. Audio-only items, captions and transitions do not consume rank. A child branch with rank `r` evaluates at parent time minus `r * staggerMs`. Component stagger applies after the instance's affine time mapping. Parent activity and clipping stay on the undelayed clock. Nested delays compose without rounding intermediate fractional milliseconds.

A repeater's ordinary source is unchanged. Additional copy `i` evaluates its source branch at containing-scope time minus its controller ranked delay and `i * timeOffsetMs`. Positive values delay copies and negative values advance them. Each copy still intersects the repeater controller's own half-open interval (including its ranked delay) and its ancestor visibility. Existing one-based transform/opacity offsets, occurrence order, visual-only source rule and expansion limits remain in force.

Supported visual position X/Y, scale X/Y and opacity channels on groups and component instances use the parent's own item-local clock before child delays. Their sampled transforms compose outside descendants; sampled opacity multiplies descendant opacity. Deferred channel properties, audio inheritance, audio repetition, expressions, arbitrary paths and network resources remain unavailable.

Editor-core validates values and derived clocks and owns the scene facts shared by frame preview, range preview, drafts and export. Typed standalone and alias-aware batch edits preserve optimistic revisions, atomic rollback and undo/redo. Core migrates current state and every retained history snapshot under the project lock to schema 26. Older binaries reject schema 26 as a future version. Invalid values return non-retryable `INVALID_ARGUMENT`; stale revisions retain retryable `REVISION_CONFLICT`.

A newly created group retains its existing identity `transform2d` default. To animate its parent channels, first clear `transform2d` with `update_item` and then set the channels; these operations can use the creation alias in the same batch. Existing transform2d/channel conflicts stay invalid. Explicit zero clears a timing value; omission on an update preserves it.

Before publication, store orchestration uses canonical renderer-neutral preflight on final affected standalone, batch and draft candidates and every retained snapshot. Unsafe clocks, overflow, expanded budgets or excessive known inherited raster bounds fail atomically with `INVALID_ARGUMENT` before generated materialization, font publication, revisions, history or draft writes. Intrinsic primitive sizes and recorded media dimensions are checked; unavailable resource measurements still require final renderer checks. The renderer keeps existing fallback and fails closed when required dependencies are missing.

Video frames retain the backend's existing output-frame resampling: mapped source presentation timestamps are rounded to the final output frame grid, then duplicated or dropped as needed. This final raster sampling does not round the intermediate affine occurrence clocks or change half-open activity. Audio retains its independent continuous trim and component retiming.

Fractional visual loop phases remain unrounded before cycle mapping and curve interpolation. For example, a 0.995-rate component at root 100 ms samples local 99.5 ms: repeat position keys (0,0), (99,100), (100,0) produce position 50, without wrapping early to zero. This applies to parent stages and animated descendants in frame, audiovisual range, materialized draft and export.
