# Design

The combined schema31 model includes issue46 AnimationPresetParameters::Scalar|Pack. Scalar remains its original untagged closed JSON form; Pack is selected by its closed kind tag. Historical valid preset/compiler IDs remain accepted structurally, without current catalog lookup or recompilation. Effective curve/iterations, property membership, matching targetless source channels and impact motionBlur validation remain authoritative.

Pre30 raw Pack kinds remain forbidden; pre31 raw retained clocks remain forbidden. Recognized30 passes the actual merged decoder and complete semantic/source validation, then migrates only schema version in cloned current/components/all retained undo/redo snapshots. Source records, channels, curves, loops, motion blur, markers, IDs, revisions, timestamps, assets and fonts remain unchanged. Already31 valid clocks and both provenance variants reopen idempotently. Unknown future versions fail closed.

The store owns full validation and supplies the existing owner-neutral recovery callback. Recognized30 journals may recover only after complete current/history semantic validation and then undergo normal locked atomic31 migration; invalid journals retain PROJECT_RECOVERY_FAILED and authoritative bytes. Ordinary unsupported future schemas retain their established error. Migration failpoints keep the existing recoverable publication protocol; no partial history generation is published.

Pack split/trim/duplicate continue issue47 retained-source behavior, preserving exact original provenance records and primitive keys while composing clocks; no resampling or preset lookup. The Pack compiler initializes new property clocks to absent, preserving unrelated clocks. Contracts advertise schema31, include both Pack and clock envelopes, and retain feature-specific capability minimum versions.

Work is isolated in a local integration worktree based on47 with46 merged locally. Original published branches remain unchanged while the integration tree is verified. Intended final dependency order is46 then47; any draft rebase/stacking will preserve both commit bundles and requires final mandatory checks and exact-head CI. Independent Sol medium review must examine migrations, retained snapshots and pending-PR compatibility before readiness.

Native amendment: FFmpeg6 bilinear geq identity pixel lookups at the last atlas row/column copy an inner neighbor, inflating static reference and late-frame dynamic rectangle borders. render_plan affine pipeline already uses explicit nearest identity channel lookups for Shape; extend only that pointwise policy to Rectangle premultiply and final unpremultiply/opacity stages. Retain all four coordinate remaps and fx/fy bilinear geometric blends unchanged, and preserve media/text orientation paths. This realizes the existing RGBA equations without synthetic edge pixels. The independent static reference's vignette amount0 is an identity RGB/alpha operation and selects a full transparent workspace. Source/retained interior, seam, turn and exhaustion tests run unchanged at all three render intents on both required FFmpeg versions; release goldens and graph/budget contracts are rechecked without lowering tolerances or suppressing checks.

Sampled CPU-raster cadence amendment: in build_render_plan's sampled_input branch only, prepare input with fps={canvas.fps},settb=AVTB before existing setpts/format/overlay. Default25fps looped PAMs otherwise schedule a pre500ms sample at480ms under FFmpeg6, producing a black frame at an exact500ms trim seam on a10fps canvas. Saved-graph synthetic PAM reproduction confirms fps10 fixes this while timebase-only AVTB does not. The AVTB precision step preserves the existing absolute millisecond placement for interval starts that are not canvas-frame multiples, such as1513ms, instead of quantizing them to the new fps filter's coarse timebase. Already canonical-fps encoded sampled intervals pass unchanged; no source evaluation, retained clock, visible boundary, geometric interpolation or ordinary media cadence changes. Verify actual sampled PAM contents/PTS, non-frame-aligned interval placement and unchanged independent seam comparisons under both FFmpeg versions, then full native/golden/lifecycle/cache parity.

Canonical sampled activity amendment: render_artifact/extended_visual's draw callback already samples the actual timeline and emits empty pixels when a layer is inactive; interval/export streams encode this activity per frame, and a point preview is frozen at its requested sample. Existing sampled motion-blur compositing already omits an extra FFmpeg enable expression because pixels enforce the sampler's shutter/activity policy. Apply that same rule to all sampled_input compositing: keep prepared cadence/precision/placement, format, overlay coordinates and eof_action=pass, but remove only the redundant floating t enable expression and its conditional branch. Real1600ms sampled PAMs exactly match the independent source600 oracle; the original graph is black, while replay omitting only that enable matches MSE0. No epsilon, time quantization, widened visible bounds, ordinary-media enable change or oracle tolerance change is introduced. Verify inactive400/1000ms edited gaps and1500ms draft gap plus active1600ms, all intents and both backends; preserve existing shutter rules and EOF behavior.

Fractional precision amendment: accepted clockoffset2^52/local0.25/keys0→10/infinite repeat currently samples6 instead of equivalent reduced-offset6.25. Internally split represented nonnegative local f64 into exact whole and fractional parts, add the signed integer offset to the whole with checked arithmetic, clamp negative source time as before, and compare/reduce first key, period and finite budget using integer arithmetic before carrying the fraction. Ping-pong reversal carries an exact signed fractional displacement (or equivalent integer borrow), avoiding premature rounding of1-f near a key boundary. Carry the split time through scalar/compound and evaluated legacy key selection; compute interpolation progress relative to integer key origins, keeping the fraction separate until normalized progress. Retained scalar bounds must use exact endpoint comparisons/progress or the existing conservative full-cycle enclosure. Keep existing integer sampling unchanged, accepted ranges/schema31 unchanged, and do not claim to recover fractions already absent from the incoming local f64.

Renderer expressions must likewise reduce retained integer offsets/loop phases and subtract integer key origins before converting constants or combining them with local floating time. Handle before-first and negative-source holds, finite budget/exhaustion, repeat/ping-pong turns and nonloop short segments near huge origins consistently with the shared sampler. No giant floating addition before modulo or relative segment interpolation may discard a represented local fraction. Validate equivalent small-phase references at ±2^52 and near the accepted safe limit, scalar/compound/legacy samples, conservative bounds and actual backend expression/native parity. Coordinate ownership: core sampler author owns animation.rs; renderer author owns render_plan.rs; independent review must cover both.
