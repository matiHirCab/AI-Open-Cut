## Decisions

### 1. Stable local geometry, density and raster boundary

Compile sampled VectorPath with canonical implicit closure/fillRule, existing adaptive contour subdivision tolerance 0.25/rho, maximum 65536 segments per mask and existing scene total1048576 segments counting mask plus ordinary graphic contours at each corresponding sampled scene. Existing ordinary-geometry limit scope remains unchanged; every actual mask shutter compilation additionally charges the per-output-frame mask work budget. Move-only/empty drawable geometry produces coverage 0; no stroke or source support is manufactured. Provably no-drawable geometry uses an analytic zero mask without local raster/EDT/feather allocation, while inversion/combination still applies within owner domain. A merely empty raster after filling retains the defined no-seed distance behavior. Mask transform anchor uses current sampled analytic unexpanded geometric bounds. Position units remain owner-local #50 units; owner's post-crop/clip pre-effect logical extent resolves normalized positions, as defined in the authoritative coordinate/interface section below.

Let owner density be the canonical source raster pixels per local project pixel. Choose rho=max(1,ownerDensity*maximum singular value of sampled mask affine linear part), without integer rounding. All local extents, density and inverse affine facts must be finite. Reject noninvertible/unsafe inverse transforms and raster-coordinate conversion displacement greater than0.25 grid pixels before publication/output; never silently clamp affine coefficients. This is an explicit renderability check, not a new arbitrary authored field bound.

Generate antialiased geometric fill C in[0,1] on a local grid at pixel centers, using existing canonical contour/fill coverage semantics (initial tiny-skia coverage boundary, alpha byte/255). Source paint is evaluated as floating premultiplied linear color through existing paint_at, not converted via intermediate encoded RGBA8. Extend analytic geometry bounds by ceil(abs(e)*rho)+ceil(3*f*rho)+2 grid pixels in every direction before allocation; align origin outward by floor/ceil grid rules. e is signed expansion and f feather sigma in local pixels. The transparent padded exterior is semantically real; finite allocation edges must not masquerade as geometry boundaries or crop the required support.

### 2. Exact approved alpha-aware grid expansion

Do not threshold coverage at0.5: that erases subpixel support. At nonzero e, compute exact squared Euclidean grid distance fields to two sets: I={pixels with C>0}, O={pixels with C<1}. Distances include all antialiased support and the explicitly padded transparent exterior. Pixel centers are integer grid coordinates; squared distances are integer (dx²+dy²), not Manhattan/Chebyshev approximations. Use two separable row/column lower-envelope distance transforms, O(P), with integer/rational envelope decisions and deterministic lower-index tie breaking. Infinite/no-seed is represented as absence, never an arithmetic float infinity. No per-pixel search over radius or all path segments is permitted.

For each pixel with partial 0<C<1, d=C−0.5. At C=1, d=sqrt(D_O)−0.5; at C=0, d=0.5−sqrt(D_I). At nonzero e produce C_e=clamp(0.5+d+e*rho,0,1). At e=0 bypass distance processing and return original C exactly. Wholly empty I produces C_e=0 for all e; move-only geometry stays empty. O is guaranteed by transparent padding for nonempty fills. This is a specified alpha-aware grid signed-distance reconstruction, not a claim of exact continuous vector offsetting. Positive expansion grows support, negative contracts; partial samples retain their subpixel seed/value rather than being classified away. Independent small-grid brute-force nearest-center distances must match it exactly before raster integration.

This refines #50's deliberately deferred pixel algorithm. Expansion applies to geometric fill support, not painted alpha/luminance: dark or a=0.25 paint must not disappear merely because its brightness/alpha is below0.5. Evaluate original Paint at the same original local coordinates over C_e; no gradient endpoints/stops are stretched with expanded bounds. The precise executable stage is geometric fill→signed expansion→original-coordinate paint/channel extraction→feather→mask affine/opacity→inversion→declared scalar combination. Amend #50 stored-order wording explicitly to this sequence; model meaning/field units stay unchanged.

### 3. Coverage channel, feather and transform

paint_at returns premultiplied linear RGBA. Alpha B=C_e*A; luma B=C_e*(0.2126*R+0.7152*G+0.0722*B_color). Color under alpha 0 contributes0; gradient interpolation retains existing premultiplied linear semantics. Channels therefore differ for colored/dark paint while geometry support is independent.

Feather sigma=f*rho uses the normalized discrete Gaussian kernel exp(−0.5*(k/sigma)²) for k=−ceil(3*sigma)…ceil(3*sigma), one horizontal and one vertical pass, transparent extension with no edge renormalization. Sigma0 bypasses exactly. Use floating scalar coverage; deterministic accumulation order is left-to-right horizontal then top-to-bottom vertical. Kernels/taps and passes are explicitly charged before execution. This is separable O(P*K) work with a hard inclusive budget, never a radius loop launched before accounting. There is no approximate box/recursive/FFT substitute that changes the approved kernel.

Inverse-map each owner-local source-raster pixel center into the mask raster, bilinearly sample scalar coverage with transparent extension using existing pixel-center convention, then multiply sampled mask.transform.opacity once. Inverted masks return1−B within the owner source raster domain. Combined coverage is seeded0 for first add/exclude,1 for first subtract/intersect; operations are add=A+B−A*B, subtract=A*(1−B), intersect=A*B, exclude=A+B−2*A*B. Empty stack bypasses all new mask code with identity1. Multiply all four owner premultiplied components once before existing effect padding/blur/glow and owner/ancestor transforms. Masks cannot revive removed crop/clip coverage, extend owner support, move owner anchors or multiply inherited opacity twice.

Float coverage/results must remain finite in[0,1], allowing only existing 1e−6 absolute f32 roundoff; clamp valid roundoff, fail larger violations. Numeric independent coverage oracles use1e−6 absolute tolerance, final uncompressed byte checks at most 1 byte. Existing shared native tolerance is SSIM≥0.99, decoded PCM RMS≤0.0001 and alignment≤1 output frame; exact lossless same-intent/same-input checks supplement these.

## Alternatives Considered

Per-pixel nearest-segment or radius searches have uncontrolled work; separable exact EDT is linear. Continuous true vector offsetting requires robust self-intersection/topology changes beyond typed path-mask rasterization; the explicit grid algorithm is deterministic and independently testable. Separable exact Gaussian with charged taps preserves #50 feather meaning; approximate box/recursive blur and FFT variability were rejected. Rendering all masks at fixed1 density aliases large transforms; density aware of owner and mask transform retains existing graphics rules but may fail bounds. New set_mask_channel operations duplicate existing channel surface. Reusing existing graphic/effect property names would ambiguously reinterpret target compatibility; unique mask names are additive.
