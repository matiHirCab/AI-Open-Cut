## Decisions
Use a private process-port geometry probe on canonical managed paths, once per transformed asset per preflight. Select the first video stream, obtain positive width/height and display rotation, derive and round its angle from the full display matrix (the printed rotation truncates fractional degrees), normalize it, and swap dimensions only within FFmpeg's strict one-degree quarter-turn tolerance. Rotation/flip rasterization stays with FFmpeg; other orientations preserve its existing source extent. Missing orientation means identity; malformed metadata or failed probing must fail with existing typed errors. Do not alter persisted probe facts or public contracts.

Core defers media affine evaluation to the same pure finalizer used by text. Renderer preflight validates references and input values, resolves bindings, measures and validates text bounds before any metadata process call, gathers oriented media measurements, finalizes all affine bounds, and checks backend support. Only then may entry points inspect collisions, allocate temporary names, create workspaces, write resources, and execute rendering. Reuse all measured data and paths. Backend metadata inspection is explicitly permitted read-only work, distinct from rasterization and render execution. No new private-owner dependency edge.

Vendor DejaVuSans and DejaVuSerif with their redistribution notice for the font unit test. Configure native tests using the existing three environment variables and required-mode behavior. Ordinary correctness runs skip native-only cases when all configuration is absent; partial configuration or required mode without dependencies fails. All subprocesses use configured paths. Add the integration target to the Linux native parity command and protect it in exact policy tests.

## Verification
Cover rotations 0/90/180/270, mirrored and non-quarter-turn metadata, invalid probes, repeated assets, missing references, font metrics without installed fonts, overflow with both collision states, zero writes before validation, and native configuration with no PATH dependency. Compare actual pixels and frame/range/draft/export SSIM and audio/timing tolerances. Run full required Rust, bridge, policy and native checks. Three-platform correctness remains CI-required; local Windows cannot claim execution on Linux/macOS.
