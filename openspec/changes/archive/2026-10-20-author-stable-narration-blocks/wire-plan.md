# Closed contract and independent oracle plan

These shapes and limits are normative precision for the approved change. All objects deny unknown fields; omission and null are distinct. New manifest/block/group IDs are UUID strings; native project/track/item/asset/caption/cue references are nonempty strings of at most128 UTF8 bytes and must resolve exactly under existing native validation (including m_<uuid> cue IDs), all milliseconds/scalar offsets/revisions/versions are nonnegative safe JSON integers (versions positive); paths are internal headless inputs only, never CLI outputs. Existing CoreError/BridgeError codes/retryability are retained, no new catalog code.

## Shapes

- PlanInput: `{sourceText,profileId,expectedVersion,maxTextCharacters,boundaries?}`. boundaries is an optional nonempty array of scalar end offsets; null rejected. maxTextCharacters is positive <=4096 and comes from current provider status (caller-declared budget on direct core calls). The workflow MUST preserve invalid caller budgets unchanged for authoritative core rejection; provider-cap reduction applies only to valid caller budgets and MUST NOT normalize an invalid budget into an accepted plan. No per-block automatic profile application on reopen. PlanResult: `{id,sourceText,maxTextCharacters,blocks}`.
- PlannedBlock: `{id,startScalar,endScalar,paragraph,displayText,request}`. request is the existing closed resolved SpeechSynthesisRequest including required pinned narrationProfile. `request.text === displayText.trim()`. The profile snapshot is resolved once per plan and cloned; core checks that all blocks have the same non-text request fields and attribution. source spans cover source exactly in initial plans; detached persisted blocks may have gaps.
- PreparedBlock: `{block,spokenSegments,spokenText}`. These are bridge-declared preparation intent. spokenSegments comes only from existing prepareSpeechSegments(request); spokenText equals exact segments joined with LF. No estimated times. Core validates sizes/nonblank segments/join equality and exact block/request/provenance correspondence, NOT equivalence to an independent speech transcription.
- CommitInput: `{projectId,expectedRevision,plan,trackId,startMs,blocks,markerPolicy?,caption?}`. blocks is the complete ordered array of `{prepared,path,durationMs,origin,probe}`; origin is existing SpeechSynthesis generated provenance and must equal planned request exactly. markerPolicy is existing SpeechMarkerPolicy, default none. caption is optional `{trackId,granularity}` with granularity sentence|word, no inference/fallback if the requested actual alignment array is absent. Captions use existing default native caption style and exactly the actual segment text/start/end plus the item's actual offset. All actual segment/provenance constraints remain existing core rules. At most100 total requested caption+cue creations across the entire group; reject before importing media if exceeded. Existing root tracks and locks are mandatory; components are excluded from this slice.
- StoredBlock: `{id,startScalar,endScalar,paragraph,displayText,request,spokenSegments,spokenText,binding}`. Binding: `{trackId,itemId,assetId,startMs,durationMs,sourceInMs,captionRefs,cueRefs}`. captionRefs: array of `{id,text,startMs,durationMs}`; cueRefs: array of `{id,name,timeMs}`. sourceInMs=0 on initial publication. The snapshot is compared with native references on every final candidate; audio gain/hide/mute and caption style are independent presentation state, not manifest identity. IDs are unique across manifests/blocks/owned refs as applicable, asset/item each uniquely owned by one block.
- StoredManifest: `{id,sourceText,maxTextCharacters,blocks,markerPolicy,caption?}`. markerPolicy is materialized even for default none; caption is omitted for no opt-in, otherwise the closed requested trackId/granularity selection. Core validates owned count/text/time/source against these selections and actual alignment using shared policy selection. Empty manifest prohibited. CommitResult: `{write,manifest}` using existing WriteResult and exact StoredManifest.
- Headless new tags: `narration_blocks_plan` plus PlanInput as `input`; `commit_narration_blocks` plus CommitInput as `input`; `detach_narration_block` with projectId,expectedRevision,manifestId,blockId; result uses existing WriteResult. No aliases/new EditOperation variant. Existing protocol operations and MCP tool identifiers remain intact; project/status schemas deliberately move46->47 and project response adds narrationManifests, so affected MCP output structural schemas must be synchronized without new tools.
- Persistent CLI commands: plan(input), preview(plan,groupId?), commit(projectId,expectedRevision,trackId,startMs,groupId,markerPolicy?,caption?), discard(groupId), reconcile(groupId), abandon(groupId); output is one closed result or existing sanitized typed error per bounded JSON line. plan/status may expose actual provider readiness; no inference during plan. preview partial failure returns completed opaque tokens/groupId and error without native mutation; explicit preview with groupId requires exact equality with the retained plan and generates only remaining blocks, never silently starting over. A partial group cannot commit. CLI/group IDs are UUIDs and process-local, not durable jobs.

Existing source request schemas cannot express immutable pinned attribution without selecting the library again. Add a bounded internal narration-block preview entry on the existing SpeechApplicationService: validate the resolved request against current status/voices/speed via the existing resolver, verify the prepared text using prepareSpeechSegments, preserve the supplied exact profile snapshot and route generation/retention through the same owned preview helper. Do not resolve the profile again, introduce a new public provider protocol, duplicate text semantics or change ordinary preview behavior. A small extraction of the existing preview-owned cleanup helper is allowed and must have legacy regression evidence.

## Budgets

No splitting/truncation to satisfy a failed bound. Each effective request serialized<=128KiB (existing pronunciation100/term128/spoken256/pause5000 preserved); each prepared plan/manifest<=512KiB serialized UTF8; project manifest array<=4MiB, <=32 manifests and<=256 live blocks. <=100 caption+cue refs/group and<=100/block; live references total bounded by existing native limits as well. Native input envelope<=16MiB including actual alignment; generated path<=4096 UTF8 bytes, existing path policy still authoritative. Reject overbudget before resource import/publication. Byte counting must abort during bounded serialization rather than allocate an unbounded result.

CLI input line<=16MiB raw UTF8 (stream bounded before parse), response<=1MiB and session groups<=4, total group tokens<=128; preview audio ownership remains the existing artifact retention, not a new audio cache. Project-state results used only internally for reconcile can exceed CLI result budget; output is bounded summary/digest, not all project content. Maximum TTL remains config.generatedArtifactTtlMs; original token deadlines are never extended. Completion does not permit additional retained groups beyond these budgets. Sequential line dispatch guarantees one active session command, while the application lease owner rejects concurrent external token access. No plaintext full script logging; diagnostics include only bounded IDs/counts/errors.

## Leases and uncertainty

States: available -> leased -> consumed (authoritative ack), available (trustworthy nonpublication), or quarantined (unknown publication). Lease all tokens synchronously and clear expiry timers; any absent/duplicate/expired token rejects before touching any timer. Existing single commit, preview-audio/discard, cleanupExpired and provider close must honor leased/quarantined state. Close awaits all active group publication calls before owner cleanup. Failed reservation never disturbs other groups.

Known REVISION_CONFLICT/validation/path/lock failures returned by a trustworthy core error restore original remaining TTL (or dispose after settlement if expired). A process/protocol/IO failure with no trustworthy typed core result quarantines the entire group and reports `publicationUnknown:true` plus projectId/manifestId; no automatically scheduled cleanup or inferred rollback. Reconcile performs a fresh core get_state under its ordinary project lock and compares the current manifest ID, exact prepared source/request/spoken/binding intent and actual generated content hashes/native references against the retained expected commit. Exact match is a positive acknowledgement and consumes tokens with cleanup warnings; absent/mismatch remains quarantined, including after undo, and NEVER permits republication. Explicit abandon/close waits active calls, permanently retires tokens and cleans only owned temporary outputs, while retaining/reporting publicationUnknown. No exactly-once claim or uncertain auto-retry.

## Legacy edits and drafts

All owned audio track/item/asset references, audio startMs/durationMs/sourceInMs, caption text/start/duration and cue name/time remain equal to stored binding snapshots. A legacy edit changing any of these fails the entire candidate. Style/gain/visibility changes preserving semantic bindings pass. Native duplication creates unowned copies and does not duplicate manifest records. Native split changes owned interval and fails until explicit detach. Moving audio/owned captions/cues changes frozen placement and fails until detach. Explicit detach changes only one ownership entry; remaining entries may have source-span gaps and retain exact bytes, IDs, provenance and order. A later old-style regeneration of the detached item cannot alter other blocks.

Drafts remain EditDraft v2 operations; no new operation can be encoded there. Existing draft previews/rebase/commit replay over migrated project bases and use the same final binding validator. Source project/history/journal transaction atomicity stays unchanged. Raw JSON cannot forge introduced schema47 metadata on older versions, even empty/null.

## Independent literal cases (freeze before consumers)

- `"  Hola. Adiós.  "`: source scalar count16, explicit ends[8,16]; display `["  Hola. ","Adiós.  "]`, request.text `["Hola.","Adiós."]`.
- `"A😀. B."`: scalar count6, explicit ends[4,6], display `["A😀. ","B."]`; offsets are NOT UTF16[5,7]. Duplicate[4,4,6], reverse[5,4,6], missing final[4], blank prefix for whitespace, zero max budget and overlong pronunciation expansion are typed failures.
- CRLF `"A.\r\n\r\nB."`: source count8, manual ends[6,8], exact first display `"A.\r\n\r\n"`, second paragraph ordinal1. No CRLF normalization.
- Abbreviation automatic `"Dr. Ada waits. Next."`: pinned UAX29 literal ends[4,15,20] and display `["Dr. ","Ada waits. ","Next."]`. Manual ends[15,20] deliberately produce `["Dr. Ada waits. ","Next."]`; no promise of linguistic sentence recognition.
- Pronunciation ordered literals `AI->A I`, `A->Alpha` applied to `"AI."` with normalization none/chunking none yield `["Alpha I."]`; reverse order yields `["AlphaI."]`. Existing prepareSpeechSegments is the shared runtime owner; core treats prepared strings as declared intent. Repeated terms, overlapping replacement, emoji/combining text and blank expansion have independent literal cases.
- Two actual synthesis durations400ms and700ms at start100ms place intervals[100,500),[500,1200), independent of text length/estimated duration. No marker/caption is inferred from those durations. Actual supplied alignment segment0..200 of second audio places cue/caption at500..700 only if explicitly requested.
- Complete2block transaction with invalid second binding or final persistence fault must preserve byte-identical current/history/resources. Stale commit followed by explicit current-revision commit calls synthesis exactly2times total, never4.
- Detach first of3 blocks retains second/third exact IDs/spans including a source gap; native duplicate produces no fourth owned block; split/move/text mutation fails atomically until detach.
- Lease timelines cover expire-before-reserve, expire-during-core, concurrent single/group/discard, typed core rejection, success+cleanup warning, lost ack+exact reconcile, lost ack+absent/mismatch after undo, abandon and close. All uncertain branches prohibit retry and preserve truthful outcome reporting.

No fixture expectation may be filled by snapshotting the implementation under test. Ambiguous literal counts/boundaries must be corrected through independent review before freezing executable canonical fixtures.
