# Desktop compositing control design

Branch gate: record verified issue56 exact head and successful 11-job Actions run before creating issue57 branch; draft PR targets issue56 implementation branch. This candidate uses the accepted issue56 seven-effect/schema37 semantics without modifying them.

## Field matrix and representation

Root eligible visual leaves expose mask collection add/delete/previous/next/up/down; selected mask immutable stableID; channel alpha/luma; operation add/subtract/intersect/exclude; inverted; featherPx; signed expansionPx; transform position x/y and pixels/normalized unit, anchor x/y, scale x/y, rotationDeg, skewXDeg/skewYDeg, opacity. Solid paint r/g/b/a are independent f64 fields. FillRule nonzero/evenodd is editable. Selected path command retains its variant: MoveTo/LineTo endpoint x/y, QuadraticTo control and endpoint x/y, CubicTo control1/control2/endpoint x/y; Close is labelled read-only. No path command insertion/deletion/retyping. Gradient variant/coordinates and bounded selected stop offset/RGBA are visible read-only; no conversion to solid. Selection includes maskID and source revision plus command/stop index. Details remain bounded regardless of 4096 commands/64 stops, and preserve every undisplayed value.

All seven effects: Gaussian radiusPx; Glow radiusPx/intensity/color r/g/b/a; Tint color r/g/b/a; Vignette amount; Adjustment exposureStops/contrast/saturation; Flash startMs/durationMs/intensity/color r/g/b/a; Particle count/seed/radiusPx/speedPxPerSecond/lifetimeMs/color r/g/b/a. Effect IDs are immutable. Add selects new ID; reorder follows stableID; delete chooses the surviving record at the deleted index, else preceding/empty. Mask behavior identical. Integer parser is exact u16/u32, including seed4294967295; finite f64 parser round-trips all authored precision, never clamps/rounds/quantizes. Semantic limits remain core's responsibility. No reuse of quantized HexColor parser for these RGBA controls; malformed Unicode input returns parsing feedback without panic.

All seven leaf blend modes normal/multiply/screen/overlay/add/darken/lighten; matte source itemID string and alpha/luma; explicit clear; matteOnly boolean. Adding a matte is explicit via source ID and defaults channel alpha, not a fabricated implicit source. Root Group/ComponentInstance exposes effects and clip composition_bounds set/clear, omitting leaf-only controls. Audio-only eligibility derives from authoritative project asset mediaType. Components are read-only. Repeater-owner effects remain unavailable. Group/Instance masks/matte/non-normal blend/shutter/effect channels remain unsupported. Existing authored animation remains inspected by its previous controls and cannot be silently changed by compositing edits.

## Exact add defaults

New collection IDs use first unused mask-N/effect-N over complete item collection, N starts1. IDs <=128bytes; generated IDs do not change on reorder/history. Add never retypes an existing record.

## Interaction and ownership

Compositing cursor is process-local, bounded, follows stableIDs and never saved into project. Draft identity binds scoped selection, authoritative revision, animation cursor, compositing selectedIDs, path-command/gradient-stop cursor, and exact field path/updateKey. Add/delete/reorder/navigation/selection/reset/successful refresh/history/edit clear obsolete field drafts. Every mutation and collection button checks busy and needs_refresh. Later async completion cannot restore text or selection belonging to another context. Conflict displays exact core code/message/retryability, requires explicit Refresh, and never retries automatically.

Build only existing typed UpdateItem using complete authoritative masks/effects/matte/blend/clip collection values, preserving every unedited record, metadata, source clock and animation channel. Apply one mutation/revision. Core owns semantic bounds, cycles/scope, eligibility, locks, resources, missing IDs and revisions. Deleting a mask/effect targeted by an animation channel retains core's rejection and exact unchanged inventory; never delete channels to force acceptance. Parse failure does not call mutation. Successful changes reload authoritative snapshot. Reset mutates nothing. Undo/redo/reopen use existing APIs.
