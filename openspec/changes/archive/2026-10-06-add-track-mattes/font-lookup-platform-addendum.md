# Supported platform admitted directory cursors

This addendum makes the approved private admitted_font_lookup allocation contract concrete on the repository's Linux, Windows and macOS targets. It preserves the existing shared byte budget, supported font formats, configured roots, depth-first first-match behavior and default resolver. No authored filename, path, directory-count or depth limit is introduced.

On glibc Linux, the source-pinned opendir cursor allocation is sizeof(DIR) plus a buffer bounded by1048576bytes; Rust1.97 adds the directory root, Arc/mutex/cursor and current-entry owners. Before opening a directory or advancing its iterator, reserve the documented platform cursor/entry allowance plus actual root/ancestor path payload and old/new stack growth. Other Linux libc implementations require their own bound or fail closed before enumeration; a glibc proof must not silently be generalized to them.

On Windows, Rust1.97 ReadDir retains a root Arc<PathBuf>, handle and fixed WIN32_FIND_DATAW record. Its current DirEntry similarly retains root/data. Pre-admit those fixed layouts, UTF16 conversion/wildcard/name buffers and actual path/key normalization payloads before creating/advancing the iterator. Derive allowances from the pinned standard-library source and platform record limits, then qualify with independent actual capacity/peak controls.

Darwin opendir/fdopendir can eagerly cache the entire directory on a mount with MNT_UNION; ordinary nonunion cursors have source-bounded buffers. A path-level check followed by opening another descriptor is insufficient. For active lookup, open a directory File, inspect that same owned descriptor with a safe filesystem-stat wrapper, and reject an uncertifiable MNT_UNION cursor before calling fdopendir. Convert the checked owned descriptor into the safe directory iterator without reopening the path, preserving descriptor identity. On success Dir owns/closes the descriptor. Pinned nix0.31.3 releases OwnedFd before fdopendir and leaks that raw descriptor on conversion failure: save its raw value before conversion, then explicitly call safe nix::unistd::close(raw_fd) exactly once on Err. Darwin fdopendir failure leaves the original descriptor open; source-pinned error cleanup must not reconstruct ownership with unsafe code or reopen the path. Never close the saved raw descriptor on success. Normal APFS/nonunion lookup remains supported and must execute successfully. Runtime code adds no unsafe block or external subprocess. Platform support/resource failures must latch and propagate before any fallback metrics/output; ordinary existing absent-font fallback remains unchanged.

The sole additional dependency is target-macOS nix exactly0.31.3, default-features=false, features=[dir,mount] (dir implies fs). It already exists in Cargo.lock; its safe sys::statfs::fstatfs, mount::MntFlags::MNT_UNION and dir::Dir::from_fd(OwnedFd) implement the same-descriptor check and iterator. Do not call deprecated unsafe Dir::from. Only the direct core package dependency relation/necessary feature resolution may change; no unrelated package upgrade is authorized. Main receives narrow ownership of crates/editor-core/Cargo.toml and resulting Cargo.lock changes for this declaration, plus the already-approved private artifact lookup implementation. No editor-core module dependency edge or public schema/catalog/pin changes result.

Verification must include source-pinned cursor/layout bounds, pre-iteration/stack-growth rejection, unchanged depth-first first-match result, nested directories, actual returned path spare-capacity admission, ordinary missing-font fallback and latched allocation/support failures without workspace/process/output. A same-descriptor injected union classifier must demonstrate no iterator construction; actual normal filesystem lookup must run. An injected conversion-failure control must exercise the explicit close branch and verify the consumed descriptor is closed without leaking or closing a successful iterator; also test a real non-directory conversion failure on supported target without suppressions. Pin this cleanup to nix0.31.3 source semantics so a future dependency upgrade cannot silently double-close. macOS compilation/lint/tests and normal lookup are required on exact-head CI; unavailable local macOS execution cannot be reported as a local pass. Before this dependency or macOS cursor implementation is edited, root and independent reviewer must approve the exact addendum manifest. Approved glyph/measurement work can continue independently.
