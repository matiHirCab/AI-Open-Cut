# CP1 wire and independent verification plan

Planning artifact only; no executable implementation or canonical contract fixture is authorized until independent review explicitly approves this document together with proposal/specs/design/tasks.

## Closed camelCase core data

All objects deny unknown fields. Numbers representing versions/revisions/counts/times are nonnegative safe integers with the stricter native ranges retained. Required nullable fields are represented explicitly as null; absence is rejected unless the existing nested native type itself specifies a default. Arrays have unique identifiers and bounded counts; slotValues remains an ordinary native own-key map.

- `ProfileRef = {profileId: UUIDv4, expectedVersion: positive safe integer}`.
- `CaptionRole = {recipeKey: string, textSlotId: string}`; points to one existing native text/rich_text slot (actual serialized native kind tag is authoritative).
- `Recipe = {key: string, definition: ComponentDefinition}`. key equals the definition id and is unique; selected source component ids become portable local keys. Native id/name/geometry/timing/tracks/slots/markers shapes remain authoritative. All nested component references resolve to recipe keys. Slot asset defaults, media items and other supported image references use dependency keys; all resource-bearing branches are exhaustively validated and remapped. Unsupported references fail instead of being ignored.
- `FontFace = {sha256: lowercase64hex, sizeBytes: positive safe integer, faceIndex: 0, dataBase64: canonical standard padded base64}`. Managed relative paths are derived internally from existing font records, never supplied. Each face must be referenced by a valid existing opencut-text-v2 binding and all referenced faces must exist; no unused font payloads. Canonical UTF-8 pack size bounds the total raw data. Existing static-outline/core record verification remains authoritative.
- `ImageDependency = {key: string, contentHash: existing ContentHash, sizeBytes: positive safe integer, probe: existing MediaProbeFacts}`. Media kind is always image for this v1 type; hasAudio must be false and probe must agree with existing managed-image semantics. No fileName, path, projectRelativePath, origin or asset id beyond local dependency key is portable. All referenced dependencies must exist; unused declarations are rejected. Asset ids captured from source become local keys and never imply target binding.
- `PackPackage = {formatVersion:1, componentSchemaVersion:46, name:string, recipes:Recipe[], fonts:FontFace[], images:ImageDependency[], captionRole:CaptionRole|null, narrationProfile:ProfileRef|null}`. At least one recipe; zero fonts/images allowed only when no native item references them. No nested library identity/version or source project metadata. Package name is the canonical validated trimmed name.
- `SavedPack = {id:UUIDv4, version:positive safe integer, package:PackPackage}`. List uses metadata `{id,version,name,recipeCount,fontCount,imageCount,hasCaptionRole,hasNarrationProfile,packageBytes}` sorted by id; it does not emit font bytes. Get returns SavedPack. Library is `{version:1,packs:SavedPack[]}`. Serialize canonical package compactly to enforce 8 MiB; bound serialized candidate library before atomic publication to 64 MiB.
- `CaptureInput = {projectId:string, expectedRevision:safe integer, componentIds:string[], name:string, captionRole:CaptionRole|null, narrationProfile:ProfileRef|null}`. componentIds nonempty distinct, closure <=16. Capture references existing managed source data; optional profile declaration can be unavailable until apply, no provider/ambient lookup. Capture reads only raw current-schema source under its lock, checks revision and pure validation, rejects pending/linked journals with PROJECT_RECOVERY_FAILED and legacy schema with VALIDATION_FAILED before any helper that recovers/migrates, and never stages source resources. Source FontBinding warning strings are replaced with one fixed path-free capture warning when sanitization is needed; no arbitrary source diagnostics persist in package.

## Six requests and results

`operation` is the existing top-level headless snake_case discriminator; all remaining fields are camelCase. Existing success/error/event envelope and retryability are unchanged.

1. `{operation:"channel_pack_list"}` -> `{packs: PackMetadata[]}`.
2. `{operation:"channel_pack_get",packId}` -> SavedPack.
3. `{operation:"channel_pack_capture",capture:CaptureInput}` -> `{pack:SavedPack,warnings:string[]}`.
4. `{operation:"channel_pack_update",packId,expectedVersion,capture:CaptureInput}` -> `{pack:SavedPack,warnings:string[]}`. Version comparison occurs under root lock after immutable read-only capture; source staging is never created. A stale update never alters source or library bytes.
5. `{operation:"channel_pack_import",name:string,packageJson:string}` -> SavedPack. UTF-8 packageJson <=8MiB before graph deserialize. Explicit name replaces package name, using the same naming checks; new id/version1. Before typed deserialize, core runs a duplicate-aware JSON visitor for the portable package, rejecting repeated object keys at every nesting level (including slotValues and literal __proto__/constructor/toString keys), not merely duplicate recipe ids. It allows each literal key once with no prototype special case, rejects trailing data/nonfinite numbers, and bounds JSON container nesting to64. Only then typed serde deserialize applies closed fields/native types. Record arrays also enforce identity uniqueness. No CLI pre-parse-and-reserialize of imported package.
6. `{operation:"channel_pack_apply",projectId,expectedRevision,packId,expectedVersion,images:ImageBinding[],narration:NarrationChoice,application:ApplyMode}` -> `PackApplyResult`.

`ImageBinding={dependencyKey:string,assetId:string}`; exactly one for each declared image, no extraneous entries, no implicit lookup. `NarrationChoice` is a closed tagged enum `{mode:"saved"}` / `{mode:"disabled"}` / `{mode:"replacement",reference:ProfileRef}`. saved with no reference returns null. Resolved profile snapshot is existing NarrationProfile data, not a synthesized request with fabricated text. Missing profile uses existing #207 lookup error and stale version uses REVISION_CONFLICT; no new error code.

`ApplyMode` is `{mode:"instantiate",placements:Placement[]}` or `{mode:"reapply",components:ComponentMapping[]}`.

- `Placement={recipeKey,trackId,startMs,trimStartMs,durationMs,timeScale,staggerMs,slotValues,transform,transform2d,hidden,zIndex,parent}` uses exactly existing AddComponentInstance field types and semantics, with explicit values (no parallel defaults). transform2d is existing Transform2D or null; hidden is boolean; zIndex is existing signed32 integer; parent is existing ParentReference or null. componentId is supplied by recipe-key remapping. At least one placement and <=32; target tracks must exist and satisfy native locks. No implicit track creation or source timing/canvas override. Existing native geometry/timing behavior is preserved when target canvas differs.
- `ComponentMapping={recipeKey,componentId}` covers every recipe once with distinct existing target component ids. Reject incompatible/locked/native-invalid replacement using existing operations. Reapply does not insert new instances or silently expand mapping.
- `PackApplyResult={write:existing WriteResult,pack:{id,version,name},components:AppliedComponent[],narrationProfile:existing NarrationProfile|null,captionRole:AppliedCaptionRole|null}`. `AppliedComponent={recipeKey,componentId,beforeDigest:lowercase64hex|null,afterDigest:lowercase64hex,changed:boolean}`. Instantiation beforeDigest=null/changed=true. Reapply digest is SHA256 of UTF-8 compact native ComponentDefinition JSON after recursively sorting object keys lexicographically; arrays and values (including stable identity-bearing data) remain in native order. There is no claim of visual-equivalence hashing. `changed` compares these exact digests. `AppliedCaptionRole={componentId,textSlotId}` points to materialized definition; it is result metadata only, never new project fields. write carries native project revision/changed ids/aliases/warnings and normal undo semantics. Canonical native bytes determine numeric serialization; the same frozen fixture expected digest is consumed by Rust/TS tests.

Pack not found and invalid package use existing VALIDATION_FAILED. Version mismatches use REVISION_CONFLICT; missing explicit dependency uses DEPENDENCY_UNAVAILABLE; other errors preserve existing core codes. No durable job semantics or MCP tool additions. Invalid foreign ids and extra bindings fail closed.

## CLI

Source entry accepts exactly one of list/get/capture/update/import/export/apply. list has no params; get/export receive `{packId}`; capture/update/apply receive their corresponding fields without operation. import takes portable package raw JSON stdin and an explicit command-line name argument, forwards raw text to core; no arbitrary package paths. export emits only PackPackage JSON. Other commands emit the documented result JSON. Bounded stdin UTF-8 decode rejects malformed input; <=9MiB request wrapper and <=9MiB output before stdout emission. packageJson remains <=8MiB. Errors use existing bridge/native translation; rejected oversized output must not claim an already completed native write was rolled back. Library metadata is bounded so normal responses fit; writes are not automatically retried. Source docs must state this post-effect output boundary explicitly.
