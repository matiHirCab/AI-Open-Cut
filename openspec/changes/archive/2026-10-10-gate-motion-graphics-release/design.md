**Goals:** Make the eight requested limit areas and complete-scene native execution mandatory/non-vacuous; measure a bounded default-core workload honestly; reject malformed/exceeded/absent observations; retain authoritative rollback/history/path/error semantics and exact-head CI evidence.

**Non-Goals:** Production limit/renderer/DTO/schema/provider changes, universal latency promises, golden updates, public benchmark API, inference/listening quality, rescue film or broad fixture cleanup. No generated media/build output is added to version control; CI uploads actual media/reports as owned evidence.

## Decisions

### Canonical closed case inventory

Use a private versioned verification inventory with exactly depth/SVG/repeater/particles/render-plan/preview/memory/timing groups and explicit Cargo target/selector descriptors. Run the existing meaningful canonical inclusive-boundary/one-over, finite/unsafe input, shared work, source preflight and lifecycle assertions; supplement genuine coverage gaps with focused owning-layer tests. Refuse zero-test, ignored/skipped, missing/duplicate-group or failed execution. A selector's name must actually appear as a passing test; successful Cargo exit alone is insufficient. Existing complete-reference failure/history tests retain invalid input, missing reference, revision conflict, late atomic rollback and reopen coverage.

Alternative considered: transport-side domain validation or a copied boundary algorithm. Both create a second owner; the inventory invokes authoritative tests and never enforces project semantics itself.

### Default native core and instrumented MCP evidence are separate

Add an isolated integration workload compiled in release/default/no-default-features mode, reuse the unchanged core reference-scene support/recipe, and render actual frame/range/export/history/reopen through the public core API. Keep default builds free of the private cache feature. The native integration case is explicitly ignored in ordinary unconfigured workspace runs and mandatory invocation selects it with --exact --ignored; its execution guard must require one actual pass with zero ignored cases and a fresh strictly validated report. Observe actual direct FFmpeg process command lines with the private process-tree sampler; never disguise a forwarding wrapper as a direct binary. On existing cache-eligible ELF/PE platforms, warm frame reuse must avoid final PNG/backend encoder calls while keeping fresh artifact identity and equal bytes. The existing Mach-O identity bypass on macOS must remain an explicitly recorded uncached fallback, with both genuine frame invocations and deterministic equal bytes. This bounded clarification preserves production behavior rather than expanding renderer identity support. Preparation and readiness/version calls are distinguished explicitly and remain included in measured cost; cache reuse is not a claim that all production preparation disappears. The existing full source/compiled MCP native test executes separately against a private instrumented headless build on every platform, with mandatory actual case/report guards. Extend only the private cache-trace assertion for existing Mach-O bypass: retain the exact original ELF/PE hit/miss/final-execution array and require the strict macOS zero-hit/zero-miss, one-through-six final-execution array. The same recipe, independent media witnesses, failure checks and deadlines remain unchanged; no relaxed inequality or privately altered renderer identity substitutes for that platform behavior. Do not rename either build as the other.

Preserve independent structural/timing/gold/audio witnesses and changed-witness controls, genuine stream metadata and matched SSIM>=0.99/floatPCM RMS<=0.0001/one-frame tolerance. #77's complete fixture remains unchanged. Default-core negative media/stale/invalid tests preserve authoritative files and pre-existing outputs; source/compiled MCP retains its existing scoped identity and cache assertions. Existing #78 default-package tests remain independently required and unchanged.

Alternative considered: reusing only #78's small portable sample, or claiming the instrumented MCP binary is a default package. Neither proves the requested complete default scene.

### Private measured workload and coarse scoped envelope

Run one discarded warm-up and exactly3 measured complete-scene captures. Each capture uses a fresh default Renderer for its initial frame, then a repeated warm frame and six-second192x10810fps audio-bearing range/export; lifecycle/reopen checks remain part of native conformance. Measure direct whole-capture elapsed time with a monotonic clock. Sample resident memory of the isolated test process plus recursively discovered native descendants at declared5ms intervals, using the existing sysinfo development dependency and a stop/join lifecycle. Exclude Cargo compilation and unrelated sibling tests from the measured root. Record actual sampler observations/units/scope/counts, max sampled RSS, fixture/font/tool/platform/architecture/build identity and capture count/aggregation. Actual child-allocation/lifecycle controls prove the collector; a private control lock isolates their process-memory baselines when ordinary test scheduling is parallel; deliberately edited report numbers are validator negative controls, never native measurements.

The new envelope applies only to this default release workload on Linux x86_64: every measured capture elapsed<=600000ms and maximum sampled process-tree RSS<=2147483648bytes, inclusive. This detects excessive bounded-workload cost; it is not an admission limit, an unsampled true-peak guarantee, a fine regression percentage or a cross-machine performance promise. Windows/macOS observations remain reported without a numerical universal budget. All three platforms still enforce the existing canonical complexity and lifecycle assertions. Strict private report validation rejects unknown versions/fields, non-finite/unsafe numbers, false capture/sampler/build/fixture identity, missing/duplicate cases and exceeded envelope values. Boundary equality and boundary-plus-one controls are required.

Alternative considered: attaching thresholds to #15, or deriving stage costs from queue time/non-additive probes. Both misrepresent existing evidence. Keep #15's artifacts, frozen references, metadata, capture counts, validators and report-only semantics untouched; no unlike-environment comparison is claimed.

### Owned bounded orchestration and workflow policy

Use a separate Windows/macOS/Linux matrix with repository toolchain pins, fixed existing four-font hashes and actual configured FFmpeg/FFprobe/Python. Build required default and explicitly instrumented binaries separately. Native/report commands are mandatory, and uploads require files. Drivers preflight inputs, collect genuine results and keep exact requested head/checked-out source identity distinguishable. All spawned processes are owned; timeout/error paths terminate and settle their own process trees, retain relevant diagnostics and fail without masking. Test timeout cleanup through an actual owned descendant fixture. Existing production cancellation controls, 1500ms/5000ms assertions and protected CI commands remain unchanged.

Policy tests reject platform/pin/command omissions, false default-feature flags, skip/report substitutions, failure masking and golden mutation. Exact published-head terminal native matrix plus existing required CI is necessary before #80. A local Linux pass cannot be presented as another platform's proof.

Alternative considered: modifying the protected foundation workflow or silently removing slow tests. A distinct gate adds evidence while preserving existing acceptance and its audit repairs.

## Risks / Trade-offs

- Sampling can miss brief resident peaks; disclose maximum sampled RSS and interval, and retain canonical allocation certificates/admission tests independently.
- Debug/OS/tool/font differences change observations; record identity/build and use the explicitly scoped envelope, without rebasing #15 or comparing unlike data.
- Complete native scenes are expensive; compile outside measured capture, keep all ten groups, and retain bounded owned process cleanup and zero-skip execution guards.
- Process sampling may miss very short invocations; require an actual observed cold final frame and synchronize sampler observations between requests. Missing observations fail closed. Native process observation never changes configured binaries or supplies output/filter readiness.
- New private fixture/report data might drift; closed identities, actual count guards, changed-witness controls and workflow-policy negatives fail closed.
