## Exact working-color equations

All channels are linear-light, unencoded working values. Let premultiplied source Cs with alpha As and backdrop Cd with alpha Ad be finite and satisfy 0≤C≤A≤1 under existing1e−6 f32 roundoff tolerance. For non-normal input, validate each source/backdrop pixel using the SAME existing f32 comparisons/arithmetic boundary as source_over_at (including f32 alpha+1e−6), THEN clamp alpha to[0,1] and each RGB component to[0,clamped A] in f32 BEFORE promoting corrected values to f64 for unassociation/blend equations; materially invalid input rejects. Do not introduce a fresh f64 tolerance check before correction, which could reject a canonical f32-accepted endpoint. Define straight s=Cs/As for As>0 else0, d=Cd/Ad for Ad>0 else0, independently per RGB channel. Do not divide by zero or insert epsilon-alpha thresholds. For non-normal modes compute these equations in f64 from retained f32 pixel values, convert final result to f32 and retain existing bounded roundoff validation/clamp:

| Mode | B(s,d) |
| --- | --- |
| normal | s (executed by the unchanged current f32 source-over path) |
| multiply | s*d |
| screen | s+d−s*d |
| overlay | 2*s*d if d≤0.5, else1−2*(1−s)*(1−d) |
| add | min(1,s+d) |
| darken | min(s,d) |
| lighten | max(s,d) |

Non-normal premultiplied output is `Co=(1−As)*Cd+(1−Ad)*Cs+As*Ad*B(s,d)` and `Ao=As+Ad−As*Ad`. Both zero-alpha operands yield canonical zero; As=0 yields the unchanged backdrop; Ad=0 yields the source, independent of selected mode. Validate source and destination before using straight values; alpha-zero nonzero premultiplied RGB outside existing roundoff is invalid, not hidden under a fallback. Finite output must satisfy premultiplied constraints. Clamp only≤1e−6 existing representational roundoff; larger invalidity fails. Normal MUST call the existing f32 source-over implementation rather than routing through algebraically equivalent new equations, so default/explicit-normal scene output remains byte-exact with prior behavior.

Overlay branches on backdrop d, not source; add is bounded RGB channel addition inside the blend function, not alpha addition, unbounded HDR, encoded addition or plus-lighter premultiplied compositing. Alpha for every mode is ordinary source-over. Preserve the initial opaque black destination. Thus a first opaque multiply layer produces black, while a first screen/lighten layer shows source; pure formula tests with transparent backdrop do not authorize a transparent scene initializer or final-only black background.
