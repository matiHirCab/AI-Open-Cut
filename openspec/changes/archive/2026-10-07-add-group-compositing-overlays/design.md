## Risks / Trade-offs

- Explicit controlled isolation changes overlap opacity and cross-track order intentionally; default scenes must remain exact. Native paired controls and explicit documentation prevent silent global changes.
- Private matte products and controlled drawing have distinct temporal ancestry. Independent singular/zero-opacity/offcanvas/query-key witnesses and immutable scoped frame facts prevent accidental plane reuse or provider omissions.
- Aggregate/query domains can increase live resources. Existing shared admission must charge real capacities before allocation, not estimated lengths afterward; overflow tests and source-cache controls are mandatory.
- Native platforms differ in color conversion/runtime speed. Keep all existing1byte/SSIM/PCM bounds, deadline5000ms, bounded test workers and failure propagation; fix defects rather than widen tolerances/timeouts.
